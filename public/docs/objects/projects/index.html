What you make

Projects

Folders you make yourself, to group songs into an album, a client, or a session.

A project is a named folder of songs. An album, an artist you write for, a single co-writing session, a batch you are pitching.

A project holds songs and nothing else. No lyrics of its own, no recordings, no concepts. Every song in a project is also in All Songs, because a project is a view of your songs rather than a place they move to.

Making one#

Open the Songs tab and tap New Project under the Projects heading, or the folder button in the top right. It asks for a name and a colour.

The colour is the same set of seven that concepts use, and it is offered already picked: each new project is suggested the colour after the last one you made, so a row of projects varies without you choosing. Tap a different swatch if you have one in mind. There is no description field, so the name is still doing most of the work. "Winter EP" beats "New Project 2".

What the colour does#

It shows in two places.

  • The folder icon on the Songs tab takes the colour, so you can pick a project out of a list of them without reading.
  • A line above the song title in All Songs, naming the project in its own colour. A song in two projects names both. A song in none has no line.

Inside a project, that project drops off its own rows. The screen is already titled with its name, so repeating it on every song would say nothing. What stays is the useful part: the other folders a song is also in.

The name is there rather than a bare coloured dot on purpose. In Lyric Genie a coloured dot already means a person: on the collaborator tabs, beside a name on the Collaborators screen, and in the green "who is in this song now" badge at the right of a song row. A folder with a name on it cannot be misread as any of those.

Putting songs in it#

Open the project and tap Add Songs, or the + in its top right. You get your whole library with a checkbox on each row and a search field at the bottom.

You can also start from the song: press and hold it anywhere in the Songs tab and choose Add to Project.

A song can be in as many projects as you like, or in none. The same song can sit in an album folder and a pitching folder at once, because a project is a view of your songs rather than a place they move to.

Taking a song out#

Swipe the song sideways inside the project.

Remove takes the song out of the project. The song itself is untouched and still in All Songs. Nothing in a project is ever the only copy of anything.

Renaming, duplicating and deleting#

Press and hold a project on the Songs tab.

Edit opens the same sheet as creating one, with the name and colour filled in. Duplicate makes a second folder holding the same songs. Delete removes the folder and leaves every song in it alone, which is the one thing worth being sure of before you tap it.
