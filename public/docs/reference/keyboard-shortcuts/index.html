Keyboard shortcuts

Every keyboard shortcut in the Lyric Genie web app, for Mac and for Windows and Linux.

Web app onlyThis is in the web app only (app.lyricgenie.app). The iOS app doesn't have it.

Lyric Genie on the web has shortcuts for most things you do in a song, and two that help you find the rest. Where Mac and Windows differ, both are given. On Linux, use the Windows keys. To get back here from the app, open the avatar menu at the top right and choose Keyboard shortcuts.

Finding a command#

Action Mac Windows and Linux
Command palette: type to find any action ⌘ K Ctrl K
Show or hide the shortcuts for the screen you're on ⌘ /, or ? Ctrl /, or ?

The keyboard button at the top of the page (in a song, Keyboard shortcuts in the song's ⋯ menu) does the same as ⌘ /: it shows a small card in the corner listing the shortcuts for that screen. It stays open while you work until you hide it, and shortcuts that need a selection first show dimmed.

The command palette lists everything you can do on the page you're on, with its shortcut beside it. Start typing ("rhymes", "perform", "dark") and press Enter. It's the quickest way to learn the shortcuts below, and the way to reach an action whose keys your keyboard can't press.

Note

On some keyboards outside the US, Ctrl Alt together is the key for accented letters (AltGr), so the Ctrl Alt shortcuts below never fire while you type. Use the command palette for those.

Shortcuts that act on a panel or a list are ignored while you are typing in a box, so they never eat a letter you meant to type.

Writing lyrics#

The lyric editor takes all the usual text-editing keys. These are the ones worth knowing:

Action Mac Windows and Linux
Start typing in the lyrics, when you're not in a text box E or Enter E or Enter
Undo ⌘ Z Ctrl Z
Redo ⇧ ⌘ Z Ctrl Y
Take the in-line suggestion Tab Tab
Dismiss the in-line suggestion Esc Esc
Next in-line suggestion ⌥ → Alt →
Previous in-line suggestion ⌥ ← Alt ←
Remove one syllable from a blank Delete (backspace) Backspace
Move the line, or the selected lines, up or down ⌥ ↑ / ↓ Alt ↑ / ↓
Duplicate the line ⇧ ⌥ ↓ Shift Alt ↓
Delete the line ⌥ ⌘ ⌫ Ctrl Alt Backspace
Jump to the previous section ⌥ ⌘ [ Ctrl Alt [
Jump to the next section ⌥ ⌘ ] Ctrl Alt ]

On Linux, Ctrl Shift Z also redoes.

The in-line suggestion keys only do anything while a suggestion is showing. Otherwise Tab and Esc behave as they normally would. See In-line suggestions.

Undo across the page#

The song page keeps one history for the lyrics, the title and the AI Context fields, and the Undo and Redo buttons in the song bar take back whichever changed last.

The keys work slightly differently depending on where you are typing:

  • In the lyrics, ⌘ Z or Ctrl Z undoes your last change to the lyrics.
  • In the title or an AI Context field, it undoes the last change anywhere on the page, the same as the Undo button.
Action, in the title or AI Context Mac Windows and Linux
Undo ⌘ Z Ctrl Z
Redo ⇧ ⌘ Z Ctrl Shift Z or Ctrl Y
Finish an AI Context field Enter Enter
New line in an AI Context field Shift Enter Shift Enter

Enter in the title does nothing, since a title is one line.

Moving between songs#

Action Mac Windows and Linux
Open the previous song ⌥ ⌘ ↑ Alt Page Up
Open the next song ⌥ ⌘ ↓ Alt Page Down

These work anywhere in the editor, including while you type lyrics. The ˄ and ˅ buttons beside Songs in the song bar do the same.

"Next" means the next song in the list you opened this one from: the same view (All Songs, Collaborative, a project or Archived), the same search and the same sort. The order is fixed when you open the song, so a list sorted by Last Edited doesn't reshuffle as you write. If you opened the song from Home or a link, it follows All Songs in your usual sort. At the top or bottom of the list it stops rather than wrapping round. Your changes are saved before the next song opens.

The longer versions still work too: ⌥ ⌘ W, G, R and T (Ctrl Alt on Windows and Linux).

Insert a blank ⌥ ⌘ B Ctrl Alt B

The workspace#

Action Mac Windows and Linux
Show or hide the right panel ⌘ \ Ctrl \
Show or hide the song panel (left) ⇧ ⌘ \ Ctrl Shift \
Open Genie, Writing tools, Rhymes, Thesaurus or Wish Workshop ⌥ ⌘ 1–5 Ctrl Alt 1–5
Open or close the scratchpad ⌥ ⌘ S Ctrl Alt S
Arrange mode, on and off ⌥ ⌘ A Ctrl Alt A
Perform ⌥ ⌘ P Ctrl Alt P
Leave an expanded tool and go back to the tool list Esc Esc

Rhyme colours and the lyric sheet have no keys of their own; find them in the command palette.

Esc deals with one thing at a time. If an in-line suggestion is showing, the first press dismisses it and the second leaves the tool. See The desktop workspace.

Wish Workshop#

These work once results are showing, and not while you are typing your wish.

Action Mac Windows and Linux
Move down the results ↓ ↓
Move up the results ↑ ↑
Run the main action on the chosen result Enter Enter
Close the panel inside Wish Workshop, or Wish Workshop itself Esc Esc

The results start with your original line. Enter does whatever the main button at the top right says, such as Replace Selection. Pick a different action from that button's menu and it becomes what Enter does for that kind of wish. See Wish Workshop.
